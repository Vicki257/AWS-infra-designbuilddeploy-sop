# 暂定设定台账

> **「今だけこうしておく」（就先这样放着）这个念头一出现，立刻加一行。**
>
> 登记漏掉的暂定设定 = **没有任何人对它的撤去负责** = 最危险的状态。

| # | 设定内容 | 追加日 | 追加理由 | 撤去条件 | 期限(Gate) | 状态 |
|---|---|---|---|---|---|---|
| 1 | | | | | | ⬜ |

状态：⬜ 未撤去 / ✅ 已撤去（日期）

---

## 检查时机

- 每周一次
- **每个 Gate**

用 `docs/92-prompts.md` 的 **A-9** 模板，把本台账和实环境一起丢给 AI，检查：

1. 过了期限还没撤去的行
2. 台账写着已撤去但实环境还留着的行
3. **实环境有但台账没有的设定**

---

## 典型的暂定设定（登记漏掉率最高的）

| 设定 | 典型的追加理由 | 典型的撤去时机 |
|---|---|---|
| ALB HTTP:80 监听器 | 证书取得前的疎通确认 | G5 |
| ELB SG 的 80 | 同上 | G5 |
| EC2 SG 的 80 ← `0.0.0.0/0` | 直接访问 Web 服务器做问题解析 | G6 |
| SSH 22 ← `0.0.0.0/0` | 构筑中的作业便利 | G6 |
| 健康检查用的临时内容 | war 部署前的占位 | G6 |
| `webapps/` 下的备份目录 | 部署前的退避 | G6 |
| 阈值下调的告警 | 发报测试 | 测试完毕时 |
